# Drive Stream promo video

A ~47 second 1080p promo for Drive Stream, made with [Remotion](https://www.remotion.dev) (React → video).

```sh
npm install
npm run studio          # preview and scrub in the browser
npm run render          # → out/drive-stream-promo.mp4 (with public/music.wav)
```

Options are passed as props:

```sh
# your repo URL in the closing scene, and a soundtrack from public/
npx remotion render DriveStreamPromo out/drive-stream-promo.mp4 \
  --props='{"repo":"github.com/you/drive-stream","music":"music.mp3"}'
```

Put the music file in `public/` (it fades in and out automatically). The included `public/music.wav` is generated by
`python3 scripts/make-music.py` (numpy only), so it's original and MIT-licensed like the rest; it's timed to the edit. If Remotion can't download its headless browser, add
`--browser-executable="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"`.

Scenes live in `src/scenes/` (problem → reveal → how it works → speed → uploads → dashboard → features → outro); timing and transitions are in `src/Promo.tsx`. Images in `public/` come from `../assets` and `../docs`.

The speed numbers in the video are the measured ones from the main README (one home connection, the same 2 GB 4K clip in both apps); the upload scene is labeled as a sped-up time-lapse.
